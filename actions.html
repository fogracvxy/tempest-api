Core API

Player actions

Hear what players do in every Tempest plugin, and report your own.

All in com.atomictempest.core, available whether or not Coins is installed.

#Hearing about money: WalletEvents and PlayerActions

java
// Every change of any wallet (after it happened)
WalletEvents.listen((player, amount, reason, balanceAfter) -> { ... });

// What players do in the economy mods: spins, wins, tickets, shop trades, daily rewards, payments
PlayerActions.listen((player, action, amount) -> {
    if (PlayerActions.SLOT_JACKPOT.equals(action)) { ... }
});

// Report your own (other listeners, such as Quests, may count them)
PlayerActions.fire(uuid, "mymod:bounty", 250);

Actions: slot_spin (bet), slot_win (winnings, also when dropped as coins), slot_jackpot, lottery_tickets (how many), lottery_win, shop_buy (cost), shop_sell (paid), daily_reward, pay, crate_open (price), coinflip_bet (stake), coinflip_win (paid), coinflip_loss (stake), quest_complete (reward paid; Core API 5, reported by Quests for every quest and achievement finished), contract_deliver (items delivered; Core API 5, reported by Contracts for every delivery to a server order), events_top (the place, 1 to 3, when an event ends), events_helped (a goal reached and the helper paid), trade_done (to each side of a finished trade that moved something; the amount is a number that always stands for the same other player), town_mayor (elected at the end of a term).

Listeners run on the thread that made the change: keep them quick, and do world or UI work with world.execute(...).

#Reference: every player action

Everything the Tempest plugins report through PlayerActions (Core), in one place. Listen once and count what you need; the amount means what the table says. Listeners run on the thread that reported: keep them quick and thread-safe.

java
PlayerActions.listen((player, action, amount) -> {
    switch (action) {
        case PlayerActions.CRATE_OPEN -> ...;     // a constant on PlayerActions
        case "jobs_level" -> ...;                 // the other plugins' actions are plain strings
        default -> { }
    }
});

Tip

Your own plugin can report actions too: PlayerActions.fire(player, "mymod_dragon_slain", 1). Use a prefix of your own so names never clash; Tempest Quests' custom triggers can count them.
