Getting started

Introduction

Build on Tempest Core and the Tempest plugins for Hytale.

The Tempest plugins can be used from other plugins (Java) and from content mods that have no code (JSON assets). Core is the base: everything shared is in com.atomictempest.core (events, leaderboards, help, settings, HUD lines, perks, and the economy bridge). Each plugin has its own small api package.

With Endless Leveling or MMO Skill Tree installed, Core's Levels and Skills give every plugin player levels, skills and what happens in them, without depending on either mod.

Every API class has a version constant that goes up when something is added. Everything in these APIs is safe to call from any thread unless it says otherwise.
