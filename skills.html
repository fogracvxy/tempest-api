Leveling and skills API

Skills (MMO Skill Tree)

Skill levels, skill XP, achievements, quests and NPC talks.

#Skills: Skills API 19+

MMO Skill Tree's skills, while it runs: one level per skill (Mining, Swords, custom skills too), skill XP, and what happens there. Found by itself, nothing of it is shipped. Works next to Endless Leveling: skills are MMO Skill Tree's own, whichever mod gives "the level".

java
if (CoreAPI.runningVersion() >= 19 && Skills.available()) {
    int mining = Skills.level(player, "Mining");        // by id or name; 0 when not known yet
    Map<String, Integer> all = Skills.levels(player);   // "MINING" -> 34, ...
    Skills.giveXp(player, "Mining", 500, "My mod: a task");   // blank skill: the one the admin chose in Core
}
MethodReturnsWhat it does
available()booleanMMO Skill Tree runs
ids()List<String>The server's skill ids, custom ones too ("MINING", "HERBALISM")
name(id)StringThe skill's name for players ("Mining")
find(typed)StringThe id a typed name or id stands for ("light armor" gives "LIGHT_ARMOR"), "" for none
subject(id)String"MINING Mining": the id and name, as in the actions below
levels(uuid)Map<String, Integer>Every skill's level, as last read; empty when not known
level(uuid, skill)intOne skill's level (id or name), 0 when not known
giveXp(uuid, skill, amount, reason)booleanSkill XP with the mod's XP banner; false when the mod is not running or the player is offline

#Its moments, as PlayerActions

What players do there is fired as PlayerActions, with the skill, achievement, quest or character after the colon. Tempest Quests counts them as goals; any plugin can.

Action (prefix constant)Fires whenAmount
mmo_skill_level:<id> <name> (Skills.SKILL_LEVEL)A skill's level went upThe new level
mmo_skill_xp:<id> <name> (Skills.SKILL_XP)XP from play (not XP Tempest gave)The XP
mmo_achievement:<id> (Skills.ACHIEVEMENT)An achievement was unlocked1
mmo_quest:<id> (Skills.QUEST)One of its own quests was finished1
npc_talk:<character id> <aliases> (Skills.NPC_TALK)A credited conversation with a character1
java
PlayerActions.listen((player, action, amount) -> {
    if (action.startsWith(Skills.SKILL_LEVEL)) {
        String skill = action.substring(Skills.SKILL_LEVEL.length());   // "MINING Mining"
        // ...
    }
});
Note

Levels are read when a player joins, every half minute and after every XP gain; a player who has just joined may have none for a moment. Core pays its own skill-level and achievement rewards (the MMO Skill Tree tab), each level and each achievement once ever.
