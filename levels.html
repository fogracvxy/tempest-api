Leveling and skills API

Player levels

Levels from Endless Leveling or MMO Skill Tree, through one API.

#Player levels: Levels API 14+

Player levels from whichever leveling mod the server runs, as Economies is for money: Endless Leveling, RPG Leveling (since 21) or MMO Skill Tree, found by themselves through their public APIs (nothing of them is shipped). Another mod's bridge can Levels.register its own Leveling. With several installed, the admin picks the one that gives "the level" on the /tempest Leveling tab, registered mods included (since 21); on "Automatic" a registered mod comes first, then Endless Leveling, RPG Leveling, MMO Skill Tree.

java
Levels.Leveling leveling = Levels.get();            // null without a leveling mod
if (leveling != null) {
    int level = leveling.level(uuid);
    int prestige = leveling.prestige(uuid);          // 0 with MMO Skill Tree and RPG Leveling
    leveling.giveXp(uuid, 250, "Quest: Miner");      // with the mod's own bonuses and level cap
}
if (!Levels.meets(uuid, 20)) { ... }                 // true without a leveling mod: nobody is locked out by a missing mod
Note

With MMO Skill Tree, level is the number the admin chose on its tab (total, combat or power level, or the highest skill), and leveling XP goes into the skill chosen there. Its skills one by one are in Skills (below).

#Levels.Listener events

All default methods: override what you need. They run on the thread the leveling mod fires on, so keep them quick.

EventFires whenCarriesSince
levelUpA player's level went up (once, even when several levels were crossed)player, oldLevel, newLevel14
prestigeA player prestiged (Endless Leveling)player, oldPrestige, newPrestige14
dungeonClearedA dungeon the player was in was clearedplayer, rank ("E" to "S", "" without)15
gateClearedA wave gate or fate zone the player fought in was clearedplayer, rank, waves15
raidClearedThe player finished a raidplayer, waves15
raidStartedA raid started for everyonename, world, waves16
java
Levels.listen(new Levels.Listener() {                  // stopListening in shutdown (or Registrations.onClose)
    @Override
    public void levelUp(UUID player, int oldLevel, int newLevel) { ... }
    @Override
    public void dungeonCleared(UUID player, String rank) { ... }
});
Note

With both mods installed only the chosen mod's level-ups and prestige reach listeners, so nothing counts twice. Endless Leveling's dungeons, gates and raids are told either way: only it has them.

#What Core does with it, and tabs for your plugin

Core pays the admin's money per level-up (with a bonus at milestones), gives the placeholders {leveling_level}, {leveling_prestige}, {leveling_xp} and more, raises rewards by level (the level bonus), and shows a "Highest levels" board while a leveling mod runs. Its settings are on three /tempest tabs: Leveling (with either mod), Endless Leveling (only while it runs: prestige, dungeons, gates, raids, mob gold by level, elite mobs) and MMO Skill Tree (only while it runs).

MethodSinceWhat it does
Registrations.levelingTab(tab)16A /tempest tab shown only while a leveling mod runs
Registrations.endlessTab(tab)19A tab shown only while Endless Leveling runs (for what only it has)
Registrations.levelingFeature(feature)16A town unlock feature offered only while a leveling mod runs

Boosts.LEVELING_XP (15) raises leveling XP: Core gives the extra through the mod each time it gives a player XP (Endless Leveling, or MMO Skill Tree in the same skill), so Tempest Events, rank perks and boosters can run "double leveling XP". With both mods installed it raises both. The extra is never boosted again.
