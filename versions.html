#Reference: Core API versions

CoreAPI.API_VERSION is the version a plugin was built against; CoreAPI.runningVersion() is the one installed on the server. Check the running version before touching anything newer than your lowest supported Core, and keep that code in a class of its own.

VersionAdded
1Core 1.0.0: Registrations, JsonFiles, Economies, CasinoSettings, HelpTopics, HudLines, Leaderboards, Placeholders, PlayerActions, WalletEvents and the rest of the first release
2AdminLog, RateLimit, and settings tab groups (tempest.admin.<group>)
3PlayLimits, HudLines.compact, Themes, dropdowns and item pickers in settings (Setting.choice, Setting.item), tab icons, ItemIcons.ids and pretty
4The Tempest board's line names and keys (HudLines.name, nameOf, keys, lineFor)
5Boosts and Registrations.boost; PlayerActions.QUEST_COMPLETE and CONTRACT_DELIVER
6Mailbox (/mail) and HudLines.startOff
7MapPlaces and Registrations.mapKind
8Unlocks and Registrations.unlockFeature, unlockProvider, onUnlock
9Activity and Perks.highestPercent
10Perks.Bonus.PASS_XP
11SettingsTab.defaults (Reset to defaults)
12JsonFiles config versions with migrations, and JsonFiles.rename
13Doctor (/tempest doctor) and Registrations.doctor
14Levels: player levels from a leveling mod
15Levels dungeon, wave gate and raid clears; Boosts.LEVELING_XP
16Levels XP, level cap, class, race, mob level, parties, raid starts, meets, hasClass, mobGold, mobKilled, playersAtLevel, serverClears, serverPrestige; Registrations.levelingTab, levelingFeature; Unlocks.isUnlocked
17Demand and Registrations.demandSource; HudLines.progress
18Rewards: item and command rewards the same in every plugin
19Skills (MMO Skill Tree) and its moments as PlayerActions; MMO Skill Tree as a leveling mod next to Endless Leveling; Registrations.endlessTab
20Setting.info (a (?) explanation beside a setting) and Setting.permission (a setting only players with that permission may change)
21RPG Leveling found by Levels; Leveling.classTier, Levels.classTier; several mods may Levels.register, each a choice in the admin's "Leveling mod"; Perks.Bonus.LEVELING_XP
22Show-when rules on settings (shownWhen, shownWhenOn, shownWhenAboveZero, shownWhenChosen), followed live in the menu; Levels.has, Leveling.has
23Hub: the Tempest hub (/tempest hub); plugins add their row and signs with Registrations.hubArea and hubPage. Comes with the next Core release
24Claims: land claims for every plugin (who owns a place, what a player may do there), answered by Tempest Claims or read from Simple Claims; Registrations.claimsProvider and publicBlocks. Comes with the next Core release
