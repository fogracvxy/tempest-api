Core API

Boards, HUD and placeholders

Leaderboards, the money counter and progress bars, placeholders and announcements.

#Leaderboards: Leaderboards

Shown on Coins' /leaderboards (servers without Coins have no leaderboard screen; registering is still safe).

java
Leaderboards.register(new Leaderboards.Board("mymod:dragons", Message.translation("server.mymod.board.title"),
        Message.translation("server.mymod.board.hint"), "server.mymod.board.count", uuid -> MyMod.dragonsKilled(uuid)));
// count key: a number with its unit, "{count, plural, one {1 dragon} other {{count} dragons}}"; null = money ("1,250 copper")

The board appears on /leaderboards after the built-in ones. It ranks every player Coins knows; players with 0 are left out. Unregister it in your shutdown().

#The coin counter: HudLines

java
HudLines.register("mymod:bounty", uuid -> hasBounty(uuid)
        ? Message.translation("server.mymod.hud.bounty").param("amount", HudLines.format(bounty(uuid))) : null);

Up to three lines show under each player's coin counter; return null to show nothing. Called every two seconds from a timer thread. With the Tempest board on (Core's panel on the right of the screen), every line shows there instead, and each player picks which ones in /board. Give your line a name for that menu (API version 4):

java
HudLines.name("mymod:bounty", Message.translation("server.mymod.board.bounty"));   // "Bounty"
HudLines.keys();  HudLines.nameOf(key);  HudLines.lineFor(key, uuid);              // API version 4

A line that is nice to have but should not push others off a full board can start off; each player switches it on in /board (API version 6; Shop's daily deal does this):

java
if (CoreAPI.runningVersion() >= 6) HudLines.startOff("mymod:bounty");

An economy plugin calls HudLines.moneyChanged(player, change) when a balance changes, so the counter shows the new amount and the change at once instead of at its next refresh, and HudLines.refreshMoney() after the currency's name or look changed (Coins does both).

#A progress bar on the screen: HudLines.progress API 17+

A bar under the money counter for five seconds: an item icon, a short line and how far along (0 to 1). A newer bar replaces the one showing. Shown even while the Tempest board replaces the counter, never when the player hid it with /hud. One HUD for everything, so it never fights another mod's HUD.

java
HudLines.progress(uuid, "Tool_Pickaxe_Iron", Message.raw("Miner 14   +6 XP"), 0.42f);
HudLines.progress(uuid, "Tool_Pickaxe_Iron", Message.raw("Miner 14"), 0.42f, 8000);   // shown for 8 seconds

#Placeholders: Placeholders

Named values per player, for scoreboards, chat formats and placeholder plugins:

java
Placeholders.value(uuid, "coins_balance_formatted");             // "1,250 copper"
Placeholders.apply(uuid, "Balance: {coins_balance_formatted}");    // {name} and %name% both work
Placeholders.register("mymod_bounty", uuid -> String.valueOf(bounty(uuid)));

#Announcements: Announcements

Big moments (jackpots, big wins, lottery winners, achievements) are posted here for integrations such as the Discord webhook. Post your own: Announcements.post("mymod_boss", "Steve defeated the Dragon!") (shown in Discord when "News from other mods" is on); listen with Announcements.listen((category, text) -> ...).
