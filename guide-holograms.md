# Holograms

Floating text and top lists.

## What players read in /guide

- Admins: change, move or delete a hologram; /holo lists them
- Admins: a new hologram like another, where you stand
- Admins: floating text where you stand; | starts a new line, {placeholders} work
- Admins: a menu of all holograms: teleport to, edit and delete them
- Admins: a live top list where you stand, such as top:money 5; /holo boards lists them

## Commands

All of them need `holograms.admin`.

| Command | What it does |
|---|---|
| `/holo boards` | List the top lists a hologram can show |
| `/holo copy` | Copy a hologram to where you stand |
| `/holo create` | Make a hologram where you stand |
| `/holo delete` | Delete a hologram |
| `/holo edit` | Change a hologram's text |
| `/holo` | Floating text: list, create, edit, move or delete holograms |
| `/holo menu` | Open the hologram menu: teleport to, edit and delete holograms |
| `/holo move` | Move a hologram to where you stand |
